Kebijakan Privasi Warung Life Simulator

Berlaku sejak 8 November 2026 (pembaruan: bagian Data Penggunaan Anonim)

Warung Life Simulator ("game") dibuat oleh NeoPaw Studio. Halaman ini menjelaskan data apa saja yang terkait dengan game ini dan bagaimana data tersebut digunakan.

Data yang disimpan di perangkat Anda

Progres permainan dan pengaturan disimpan di perangkat Anda. Game ini tidak meminta akun, nama asli, nomor telepon, kontak, foto, atau lokasi tepat Anda.

Papan Peringkat Online

Game ini memiliki papan peringkat warung antar pemain. Supaya warung Anda bisa tampil di papan, game mengirim data berikut ke server kami (layanan basis data Supabase, server di Singapura):

  • Nama warung yang Anda ketik di game
  • Jumlah pembeli yang sudah dilayani (sepanjang masa dan bulan ini)
  • ID acak yang dibuat game untuk setiap simpanan permainan. ID ini tidak berasal dari perangkat, akun, atau ID iklan, dan tidak bisa dipakai untuk mengenali Anda

Data dikirim terenkripsi (HTTPS) dan hanya dipakai untuk menampilkan papan peringkat. Nama warung dan jumlah pembeli dapat dilihat pemain lain. Jangan memakai nama asli, nomor telepon, atau informasi pribadi sebagai nama warung. Nama yang mengandung kata kasar ditolak otomatis, dan pemain dapat melaporkan nama yang tidak pantas; nama yang dilaporkan beberapa pemain disembunyikan dari papan. Kami tidak menjual atau membagikan data papan peringkat kepada pihak lain.

Saat menghubungi server, alamat IP perangkat Anda terlihat oleh penyedia server sebagai bagian dari koneksi internet biasa, tetapi tidak kami simpan di data papan peringkat.

Data Penggunaan Anonim

Untuk memperbaiki game (misalnya mengetahui bagian yang terlalu sulit, HP yang berat menjalankan game, dan berapa lama pemain bermain), game mengirim catatan penggunaan ke server kami (Supabase, server di Singapura):

  • Kejadian di dalam game, seperti membuka dan menutup game, lama bermain, hari permainan selesai, naik level, menonton iklan, dan membeli upgrade warung (dengan uang di dalam game)
  • Kelancaran game (FPS rata-rata) dan pengaturan grafik
  • Info perangkat umum: merek/model HP, versi Android, ukuran layar, besar RAM, bahasa game, dan versi game
  • ID acak yang dibuat game di HP Anda. ID ini tidak berasal dari IMEI, akun Google, atau ID iklan, dan tidak bisa dipakai untuk mengenali Anda

Catatan ini tidak berisi nama, email, kontak, lokasi, atau nama warung Anda. Data dikirim terenkripsi (HTTPS), hanya dipakai NeoPaw Studio untuk analisis dan pengembangan game, tidak dijual atau dibagikan kepada pihak lain, dan dihapus otomatis setelah 180 hari. Anda dapat mematikannya kapan saja di menu Pengaturan (tombol "Data anonim"). Saat dimatikan, game berhenti mengirim dan data dari HP Anda yang sudah tersimpan di server ikut dihapus.

Iklan (Unity Ads)

Game ini menampilkan iklan melalui Unity Ads (Unity Technologies) dan mitra jaringan iklannya. Untuk menampilkan iklan, mengukur kinerja iklan, dan mencegah penipuan, Unity dan mitranya dapat mengumpulkan dan memproses data secara otomatis, yaitu:

  • ID iklan Android, ID set aplikasi, dan pengenal perangkat lainnya
  • Alamat IP, yang dapat dipakai untuk memperkirakan lokasi umum perangkat
  • Interaksi dengan aplikasi dan iklan, seperti membuka aplikasi, mengetuk, dan menonton video
  • Informasi diagnostik dan perangkat, seperti model perangkat, versi sistem, dan kinerja aplikasi

Data tersebut dikirim dalam keadaan terenkripsi. NeoPaw Studio tidak menerima data pribadi dari Unity, hanya laporan gabungan seperti jumlah iklan yang tayang dan perkiraan pendapatan. Penjelasan lebih lanjut ada di kebijakan privasi Unity: https://unity.com/legal/game-player-and-app-user-privacy-policy

Anda dapat mereset atau menghapus ID iklan melalui menu Setelan di perangkat Android Anda.

Pembelian dalam game (Google Play)

Pembelian "Tanpa Iklan" dan "Dukung Kami" diproses sepenuhnya oleh Google Play. NeoPaw Studio tidak menerima nomor kartu atau data pembayaran Anda. Game hanya memeriksa ke Google Play apakah suatu pembelian sudah dilakukan, supaya pembelian tetap berlaku sesudah game dipasang ulang.

Anak-anak

Game ini tidak ditujukan untuk anak di bawah 13 tahun, dan NeoPaw Studio tidak dengan sengaja mengumpulkan data pribadi anak. Jika Anda orang tua atau wali dan merasa ada masalah terkait hal ini, hubungi kami melalui email di bawah.

Menghapus data

Menghapus (uninstall) game akan menghapus progres dan pengaturan dari perangkat Anda. Menghapus simpanan permainan dari menu Load Save juga menghapus warung tersebut dari papan peringkat online. Data penggunaan anonim dapat dihapus dengan mematikan "Data anonim" di Pengaturan. Untuk meminta penghapusan data papan peringkat dengan cara lain, kirim email ke alamat di bawah dengan menyebut nama warung Anda. Data iklan dikelola oleh Unity dan mitranya. Anda dapat mengaturnya melalui Setelan perangkat Android Anda.

Perubahan kebijakan

Kebijakan ini dapat diperbarui jika game berubah. Versi terbaru selalu tersedia di halaman ini.
